# M6 issue-date workload

New seed and source conversations, separate from the aborted M5 workload. Every non-null issue date must occur in an exact issue-date statement. Test-only cases distinguish an arrival-only date (refund_date=null) from distinct issue and arrival dates. Labels come from fact sheets, not model answers. All verifier disagreements are reviewed blind to Nano.

These conversations are synthetic and model-written; neither generation nor adjudication is human/domain validation. Explicit statements constrain the language and improve label defensibility. See `experiments/M6-issue-date-confirmation.md` for preregistered gates and limitations, and the run artifacts for every writer, verifier and production call.
